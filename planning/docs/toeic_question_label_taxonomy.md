# TOEIC Question Label Taxonomy

## Part 1

### Question Type
- `PART_1_PERSON_DESCRIPTION` — Tranh tả người
- `PART_1_PERSON_AND_OBJECT_DESCRIPTION` — Tranh tả cả người và vật
- `PART_1_OBJECT_OR_SCENE_DESCRIPTION` — Tranh tả vật hoặc cảnh, không có người

## Part 2

### Question Type
- `PART_2_WHO_QUESTION` — Câu hỏi WHO
- `PART_2_WHERE_QUESTION` — Câu hỏi WHERE
- `PART_2_WHEN_QUESTION` — Câu hỏi WHEN
- `PART_2_HOW_QUESTION` — Câu hỏi HOW
- `PART_2_WHY_QUESTION` — Câu hỏi WHY
- `PART_2_YES_NO_QUESTION` — Câu hỏi YES/NO
- `PART_2_TAG_QUESTION` — Câu hỏi đuôi
- `PART_2_CHOICE_QUESTION` — Câu hỏi lựa chọn
- `PART_2_REQUEST_OR_SUGGESTION` — Câu yêu cầu, đề nghị
- `PART_2_STATEMENT` — Câu trần thuật

## Part 3

### Question Type
- `PART_3_TOPIC_OR_PURPOSE` — Câu hỏi về chủ đề, mục đích
- `PART_3_SPEAKER_IDENTITY` — Câu hỏi về danh tính người nói
- `PART_3_CONVERSATION_DETAIL` — Câu hỏi về chi tiết cuộc hội thoại
- `PART_3_FUTURE_ACTION` — Câu hỏi về hành động tương lai
- `PART_3_GRAPH_OR_TABLE_QUESTION` — Câu hỏi kết hợp bảng biểu
- `PART_3_LOCATION` — Câu hỏi về địa điểm hội thoại
- `PART_3_REQUEST_OR_SUGGESTION` — Câu hỏi về yêu cầu, gợi ý

### Topic
- `PART_3_COMPANY_PERSONNEL` — Chủ đề: Company - Personnel
- `PART_3_COMPANY_EVENT_OR_PROJECT` — Chủ đề: Company - Event, Project
- `PART_3_SHOPPING_OR_SERVICE` — Chủ đề: Shopping, Service
- `PART_3_HOUSING` — Chủ đề: Housing

## Part 4

### Question Type
- `PART_4_TOPIC_OR_PURPOSE` — Câu hỏi về chủ đề, mục đích
- `PART_4_SPEAKER_OR_LOCATION` — Câu hỏi về danh tính, địa điểm
- `PART_4_DETAIL` — Câu hỏi về chi tiết
- `PART_4_FUTURE_ACTION` — Câu hỏi về hành động tương lai
- `PART_4_GRAPH_OR_TABLE_QUESTION` — Câu hỏi kết hợp bảng biểu
- `PART_4_IMPLICATION` — Câu hỏi về hàm ý câu nói
- `PART_4_REQUEST_OR_SUGGESTION` — Câu hỏi yêu cầu, gợi ý

### Speech / Audio Type
- `PART_4_TELEPHONE_MESSAGE` — Dạng bài: Telephone message - Tin nhắn thoại
- `PART_4_ADVERTISEMENT` — Dạng bài: Advertisement - Quảng cáo
- `PART_4_ANNOUNCEMENT` — Dạng bài: Announcement - Thông báo
- `PART_4_TALK` — Dạng bài: Talk - Bài phát biểu, diễn văn
- `PART_4_MEETING_EXCERPT` — Dạng bài: Excerpt from a meeting - Trích dẫn từ buổi họp

## Part 5

### Question Type
- `PART_5_PART_OF_SPEECH` — Câu hỏi từ loại
- `PART_5_GRAMMAR` — Câu hỏi ngữ pháp
- `PART_5_VOCABULARY` — Câu hỏi từ vựng

### Grammar
- `GRAMMAR_NOUN` — Danh từ
- `GRAMMAR_PRONOUN` — Đại từ
- `GRAMMAR_ADJECTIVE` — Tính từ
- `GRAMMAR_TENSE` — Thì
- `GRAMMAR_VOICE` — Thể
- `GRAMMAR_ADVERB` — Trạng từ
- `GRAMMAR_PARTICIPLE` — Phân từ và cấu trúc phân từ
- `GRAMMAR_PREPOSITION` — Giới từ
- `GRAMMAR_CONJUNCTION` — Liên từ
- `GRAMMAR_RELATIVE_CLAUSE` — Mệnh đề quan hệ
- `GRAMMAR_COMPARISON` — Cấu trúc so sánh

## Part 6

### Question Type
- `PART_6_GRAMMAR` — Câu hỏi ngữ pháp
- `PART_6_VOCABULARY` — Câu hỏi từ vựng
- `PART_6_SENTENCE_INSERTION` — Câu hỏi điền câu vào đoạn văn

### Passage / Form Type
- `PART_6_EMAIL_OR_LETTER` — Hình thức: Thư điện tử / thư tay (Email / Letter)
- `PART_6_ARTICLE_OR_REVIEW` — Hình thức: Bài báo (Article / Review)
- `PART_6_MEMO` — Hình thức: Thông báo nội bộ (Memo)

### Grammar
- `GRAMMAR_PRONOUN` — Đại từ
- `GRAMMAR_TENSE` — Thì
- `GRAMMAR_VOICE` — Thể
- `GRAMMAR_TO_INFINITIVE` — Động từ nguyên mẫu có to
- `GRAMMAR_PREPOSITION` — Giới từ

## Part 7

### Question Type
- `PART_7_INFORMATION_RETRIEVAL` — Câu hỏi tìm thông tin
- `PART_7_FALSE_INFORMATION` — Câu hỏi tìm chi tiết sai
- `PART_7_TOPIC_OR_PURPOSE` — Câu hỏi về chủ đề, mục đích
- `PART_7_INFERENCE` — Câu hỏi suy luận
- `PART_7_SENTENCE_INSERTION` — Câu hỏi điền câu
- `PART_7_VOCABULARY_IN_CONTEXT` — Câu hỏi tìm từ đồng nghĩa / từ vựng trong ngữ cảnh
- `PART_7_IMPLICATION` — Câu hỏi về hàm ý câu nói

### Passage Structure
- `PART_7_SINGLE_PASSAGE` — Cấu trúc: một đoạn
- `PART_7_MULTIPLE_PASSAGE` — Cấu trúc: nhiều đoạn

### Passage Type
- `PART_7_EMAIL_OR_LETTER` — Dạng bài: Email / Letter - Thư điện tử / Thư tay
- `PART_7_FORM` — Dạng bài: Form - Đơn từ, biểu mẫu
- `PART_7_ARTICLE_OR_REVIEW` — Dạng bài: Article / Review - Bài báo / Bài đánh giá
- `PART_7_ADVERTISEMENT` — Dạng bài: Advertisement - Quảng cáo
- `PART_7_ANNOUNCEMENT_OR_NOTICE` — Dạng bài: Announcement / Notice - Thông báo
- `PART_7_TEXT_MESSAGE_CHAIN` — Dạng bài: Text message chain - Chuỗi tin nhắn
- `PART_7_SCHEDULE` — Dạng bài: Schedule - Lịch trình, thời gian biểu
